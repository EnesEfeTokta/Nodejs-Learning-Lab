## Overview

**Node.js Learning Lab** is a comprehensive educational repository dedicated entirely to learning and mastering Node.js development. This repository serves as a structured learning environment and reference resource for future Node.js projects and applications.

### Purpose

This repository is designed with the following objectives:

- **Educational Focus**: Provide hands-on learning experiences with Node.js concepts and best practices
- **Practical Examples**: Demonstrate real-world Node.js applications through mini-projects
- **Future Reference**: Serve as a knowledge base and code reference for future Node.js development
- **Skill Building**: Progressive learning path from fundamentals to advanced Node.js topics

**Note**: This repository is entirely based on Node.js and is intended for learning purposes and future use.

## Repository Structure

Each directory contains a focused mini-project or concept demonstration:

| Directory | Description |
|-----------|-------------|
| `00-Video-operations` | Video processing and manipulation using Node.js |
| `01-rest-api-basics` | Fundamentals of REST API development with Express |
| `02-rest-api-calculator` | Building a calculator REST API |
| `03-rest-api-basic-login` | Basic authentication implementation |
| `04-basic-json-file-operations` | JSON file handling and operations |
| `05-http_ip-info` | HTTP requests and IP information retrieval |
| `06-rest-api-jwt` | JWT-based authentication in REST APIs |
| `07-File-Operations` | File system operations with Node.js |
| `08-Basic-Embedding` | Embedding and integration concepts |

## Topics Covered

This learning lab covers a wide range of Node.js concepts:

- **Web Frameworks**: Express.js setup and configuration
- **REST API Development**: Creating and structuring RESTful services
- **Authentication**: Basic authentication and JWT implementation
- **File Operations**: Reading, writing, and manipulating files
- **HTTP/HTTPS**: Making requests and handling responses
- **Middleware**: Custom and third-party middleware integration
- **JSON Operations**: Working with JSON data and files
- **Video Processing**: Handling media files with Node.js
- **Routing**: Request routing and endpoint management

## Getting Started

### Prerequisites

- **Node.js** (v12 or higher recommended)
- **npm** or **yarn** package manager
- A code editor (VS Code, Sublime Text, etc.)
- Basic understanding of JavaScript

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/EnesEfeTokta/Nodejs-Learning-Lab.git
   ```

2. Navigate to any project directory:
   ```bash
   cd Nodejs-Learning-Lab/01-rest-api-basics
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Follow the specific instructions in each project's README

## Usage

Each mini-project is self-contained and can be run independently. Navigate to the desired project directory and refer to its README.md for specific instructions and usage examples.

```bash
# Example: Running the REST API basics project
cd 01-rest-api-basics
npm install
npm start
```

## Learning Path

For beginners, it's recommended to follow the projects in numerical order:

1. Start with `01-rest-api-basics` to understand Express fundamentals
2. Progress through authentication examples (`03`, `06`)
3. Explore file operations (`04`, `07`)
4. Dive into specialized topics (`00`, `05`, `08`)
